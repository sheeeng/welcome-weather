# Whether Weather

An Oslo current-weather and short-forecast browser application with a seasonal Three.js background.

## Commands

Run `npm install` to install dependencies. Run `npm run dev` to start the local server. Run `npm test` to run unit tests. Run `npm run build` to create the production output.

## Data and Icon Sources

Weather data comes from [MET Norway][met-norway]. Weather pictograms come from [Weather Icons][weather-icons]. The wind barb follows the [National Weather Service convention][nws-wind-barbs].

[met-norway]: https://api.met.no/
[weather-icons]: https://erikflowers.github.io/weather-icons/
[nws-wind-barbs]: https://www.weather.gov/hfo/windbarbinfo
