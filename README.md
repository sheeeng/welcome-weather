# Welcome Weather

Welcome Weather is a client-side application that displays current weather and a short forecast for your location or Oslo, Norway, with a seasonal Three.js background.

## Commands

Run `npm install` to install dependencies. Run `npm run dev` to start the local server. Run `npm test` to run unit tests. Run `npm run build` to create the production output.
